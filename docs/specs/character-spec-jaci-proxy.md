# Especificação de Personagem: Jaci "Proxy" Vanderbist (Companheira — Healer Biológica)

**Visual vigente: 2D pixel-art via PixelLab** (pivô 3D→2D, ver CLAUDE.md).

> **Status:** canônico. Documento mestre. Os TRAÇOS DE IDENTIDADE abaixo seguem valendo para qualquer mídia de renderização.
> **Cross-ref:** projeto `Projects/gusworld/` — style guide aplica esta spec.

## Traços de identidade (vigentes, agnósticos de dimensão)

- **Idade:** 11 anos (mesma idade do Gus — peer mais próximo), ectomorfa severa, ascendência Tupi+Flamenga (Lua / Junto à Floresta).
- **Olhos:** amendoados, grandes, heterocromia cibernética emissiva (lentes mismatched).
- **Pele:** alva/vampírica, saturação zero, translucidez cutânea com canais vasculares finos discretos.
- **Traje:** jaleco de Kevlar cinza-claro, segmentado, com slots vazados no peito/laterais pra ampolas químicas.
- **Acessório-assinatura:** ampolas pneumáticas de vidro translúcido com fluido verde-esmeralda bioluminescente (emissão constante).
- **Role mecânico:** Healer / Buffer Biológico — nanorobôs médicos injetáveis, alteração temporária de atributos (capacidade pulmonar, resistência a toxinas), reprogramação de fauna local.
- **Vinculação ao setting:** Selve Sombria (fronteira tecnorgânica). Extrai fluidos de plantas pra sintetizar antídotos em tempo real.
- **Especialidade técnica:** bioquímica sintética + bio-hacking. Contraponto ao Gus: enquanto Gus observa natureza externamente via antena, Jaci altera propriedades celulares do próprio corpo e da flora via injeções.
- **Anti-uso:** não há violência letal biológica explícita (sem veneno, sem patógeno mortal — Pillar 4). Bio-hacking é cura, buff, neutralização.
