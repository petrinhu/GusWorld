# Especificação de Personagem: Sterling Locke (Antagonista Principal)

**Visual vigente: 2D pixel-art via PixelLab** (pivô 3D→2D, ver CLAUDE.md).

> **Status:** canônico. Documento mestre. Os TRAÇOS DE IDENTIDADE abaixo seguem valendo para qualquer mídia de renderização.
> **Cross-ref:** projeto `Projects/gusworld/` — style guide aplica esta spec.

## Traços de identidade (vigentes, agnósticos de dimensão)

- **Idade:** adulto — único adulto canônico em foco (todos os outros figurões, Gus + 6 companions, são peers 11-14).
- **Diretriz de design — desafio geométrico:** o design deve projetar imponência, frieza autoritária e ameaça através de linhas retas, ângulos agudos e silhueta monolítica inflexível, **quebrando deliberadamente a natureza cômica do formato SD**. Esse desafio (ameaça via geometria dura, não via realismo) é a assinatura visual dele e continua valendo em qualquer mídia.
- **Rosto:** perfeitamente simétrico, queixo poligonal pronunciado, expressão aristocrática de desprezo calculado.
- **Paleta monocromática corporativa:** preto-graphene polido, branco-estéril fosco, cromo espelhado. Alta reflexividade metálica nas seções de armadura.
- **Indumentária:** sobretudo monolítico rígido (armadura geométrica cônica até o solo, sem dobras orgânicas, só vincos mecânicos precisos).
- **Acessório-assinatura:** monóculo ocular criptográfico no olho esquerdo, sub-divisões concêntricas douradas, linha de laser vermelho emissivo (`#FF0000` — única ocorrência desse vermelho saturado fora de zonas de anomalia/Patch-Zero).
- **Etimologia:** Sterling (estrela > moeda > padrão de pureza indestrutível) + Locke (fechadura, criptografia, confinamento). Sonoridade ríspida monossilábica deliberada — contraste com "Gus Vector Tavus Vance" (musical, vetorial).
- **Arco filosófico:** vilão puro (sem redenção — confirmado P4). Espelho filosófico do Gus (ambos lógicos), não etário ou peer-mirror. Vê natureza como "erro de sintaxe que precisa ser trancado" e monetizado.
- **4º elemento proprietário:** Locke Core (implante neural cortical) + Rede Distribuída (enxame proxies/drones na cidade). Vantagem técnica que Gus NÃO terá nem copiará.
- **Boss final, 2 fases:** (1) Fase Rede — derrota proxies espalhados na Cúpula; (2) Fase Locke Core — Sterling exposto, decodificação via knowledge farming.
- **Vinculação ao setting:** Catedrais de Silício + Cúpula Sterling (ato 3, mesmo setting em duas zonas — exterior híbrido corrompido × interior estéril euclidiano).
- **Patch-Zero é arma corporativa vazada dele** — solto na rede internacional, foge ao controle; vira ameaça paralela.
